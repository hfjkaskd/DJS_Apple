# 丰收奖励独立回归测试

在 `output_Unity` 目录运行：

```powershell
./Tests/HarvestRewards/Run-Tests.ps1
```

默认使用本机 Unity 2022.3.62f3 附带的 Mono 和 C# 编译器。其他安装路径可通过 `-UnityEditor 'C:/Program Files/Unity/Hub/Editor/版本号'` 指定。脚本直接编译实际领域和存储源码，不启动 Unity，不下载 NuGet，不用反射，不引入 Editor 专用生产逻辑。编译产物和故障存档写入独立临时目录，结束时删除。

21 项测试覆盖：

- 默认六站目标、每站任务与24小时并行、最终168小时以及最短13天。
- 任务先完成时，离线继续计时；任务后完成时，从实际完成时进入下一站；未完成任务不跳站。第六站离线跨越全部等待后直接模拟结算。
- 阶段前事件、错误任务类型、教学事件及超量任务不会提前填充后续阶段。
- 单申请冻结、档位一次、金额不足、非法档位、冻结期间新增奖励入可用额。
- 三消及胜利重复事件、奖励重复领取、教学赠礼及首次免费倍率。
- 胜利普通奖励立即可领取；局内普通奖励保留3秒等待，不能在创建时或2秒时提前领取。
- 末组三消优先通关；该状态重启后仍不会抢弹局内礼包。
- 广告失败后基础领取、请求 ID 匹配、重复成功回调、成功次数次回合升档、两种成功次数独立。
- 结算高倍率合计概率和平滑插值、冻结余额不参与概率比例。
- 首达减速不因冻结或重启重置、未发加速补奖不再发放、UTC 回拨使用已持久化的最大时间。
- 申请、计时、任务、待领取奖励和去重序号的二进制保存与重启恢复。
- 进程重启不接受旧广告回调，仍能领取基础奖励。
- 缺失初始存档、孤立临时文件、截断和校验失败；损坏时不会清空数据或回退可能重复付款的旧备份。
- 锁定主存档使原子替换失败，旧文件逐字节保持完整；解除锁定后可正常保存。
- 无效配置拒绝启动。

验证边界：这些测试验证本地模拟账本和文件操作。Unity 场景加载、Prefab 交互、真实广告 SDK、Android/iOS 文件系统和前后台恢复仍需相应运行环境验证；该计划不提供现金支付。
