# 丰收模拟提现 · 实现与验证

## 当前可用功能

- 首页、局内、胜利结算页的 **Harvest Rewards / SIMULATION** 按钮打开奖励中心。
- 教学一次性赠礼、三消收入、局内丰收礼包、胜利奖励、首次免费高倍和首达后减速。模拟余额独立于原金币和关卡宝箱。
- 六个额度档位，完整规则展示、申请前二次确认、金额冻结、单活动申请、单档一次。
- 六阶段主线通关/三消任务，每阶段任务与24小时等待并行；最后168小时等待，完成后生成模拟结算记录。
- 离线时间按照真实经过的UTC时间计算。任务先完成时，从阶段原到期时刻推进；不会在玩家回访时重新开始等待，也不会替玩家完成下一阶段任务。
- 稳定关卡尝试ID、三消事件高水位、胜利去重；恢复已清空棋盘时检查胜负，胜利状态与下一主关一起保存。
- 显式二进制存档、完整性校验、原子替换。存档损坏或写入失败时停止奖励操作并显示错误，不把错误当成新账号重发奖励。
- 按秒刷新界面与倒计时，有效游玩只统计可操作的非教学棋盘；退出/切后台保存。

游戏沿用现有英文字体，新增页面使用英文，常驻标注模拟奖励、不可兑换现金。没有收款账号输入和真实支付请求。

## 配置与接入点

| 文件 | 用途 |
| --- | --- |
| `Assets/Resources/HarvestRewardConfig.asset` | Inspector可调整额度、阶段、等待、奖励、倍率、概率和经济预算 |
| `Assets/Scripts/Assembly-CSharp/HarvestRewards/HarvestRewardEngine.cs` | 不依赖Unity的奖励与提现状态机 |
| `HarvestRewardStorage.cs`（同目录） | 明确字段顺序的二进制存档，不依赖反射和枚举字符串 |
| `HarvestRewardService.cs`（同目录） | Resources配置、共享存档与真实激励SDK接口 |
| `HarvestGameplayBridge.cs`（同目录） | 生命周期、有效时间、局内礼包与首次达标引导 |
| `HarvestRewardsUI.cs`（同目录） | 标准Button事件绑定、数据展示、申请确认 |
| `Assets/res/local/harvest/HarvestRewardsUI.prefab` | 静态页面、布局、文字、视觉与交互配置 |
| `Tools/GenerateHarvestRewardsUI.py` | 离线生成上述Prefab和三个入口，运行时不动态创建界面 |

`EDLHEMMBABM` 在三消逻辑提交处发事件，在胜利持久化前登记奖励；`LevelData.harvestRunId` 跨快照保持，真正新开一局时重置。最后一组三消只给消除收益和任务进度，不新弹礼包。

未领取的基础奖励在下一局开始时自动入账，首次免费奖励也保留；胜利时已有的局内礼包按基础金额结算，避免离开页面造成奖励丢失。当前5分钟预算段用完后，三消加速收入暂为0，下一段开放恢复；总480预算用完仍未首次达标时每组三消2。基础礼包与胜利奖励不受该分段预算影响。这是原报告未明确的预算实现约定。

## 尚未接通的外部服务与原方案功能

激励接口为 `IHarvestRewardedAdProvider`，通过 `HarvestRewardService.SetRewardedAdProvider()` 注入。提供方需要在Unity主线程回调原请求ID及实际观看完成状态；错误ID、失败、取消和重复回调不发奖励。工程没有配置可工作的广告提供方，因此广告按钮置灰，基础领取可用，不模拟广告观看成功。

原方案中的自动广告调度、连续活跃广告分层、回流广告降频、道具激励改造仍为后续商业化工作；本次未用空SDK实现或假成功代替这些服务。六阶段提现的奖励/任务/等待核心已接入。

真实兑付需要独立的服务端账本、可信时间、支付渠道和支付状态回执；本工程只实现模拟结算，本地校验不是支付安全或反作弊服务。

## 验证与复现

1. 用Unity打开 `output_Unity`，打开 `Assets/Game.unity`，完成首次教学，或从首页进入游戏。
2. 点击任意 **Harvest Rewards** 入口，检查模拟余额、基础领取、六档、完整任务规则和确认弹窗。没有配置SDK时广告按钮应不可用。
3. 通过正常游玩积累到门槛后申请，检查可用额转为冻结额；在活动阶段推进相应通关或三消任务。
4. 关闭并重启，检查余额、申请进度与等待恢复。不要删除存档或调整系统时间来模拟真实业务完成。

自动领域回归：`Tests/HarvestRewards/Run-Tests.ps1`，使用Unity自带Mono编译实际领域与存储源码，无NuGet。已实际通过21项，覆盖计时边界、离线、冻结、重复事件、首次奖励、末组、存档损坏与替换失败。普通胜利奖励立即可领，3秒等待仅适用于局内普通领取。

Unity验证入口：`HarvestRewardValidation.ValidateAndRender`。本机Unity `2022.3.62f3 (96770f904ca7)` 已完成脚本编译、Prefab/配置/标准Button检查及离屏渲染检查。原工程版本文件保留 `2022.3.62f3c1`；本次未将自动导入产生的版本、混音器、LightingData和日志变化纳入功能提交。

离屏截图位于 `Tests/HarvestRewards/Artifacts`，用于Prefab布局核对；静态截图不代表游戏已经运行到截图中的关卡或数值。尚未执行Android/iOS设备测试、真实SDK回调或真实付款测试。
